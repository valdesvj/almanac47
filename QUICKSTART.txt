C47_nav - QUICK START (install and run)
=======================================

You need two files from build/ (convert each .txt to .p47 with rejig first):

  rejig build/NAVFULL_NOTBL.txt -o NAVFULL_NOTBL.p47
  rejig build/NAVINIT_FAST.txt  -o NAVINIT_FAST.p47

  NAVFULL_NOTBL  the programs that stay on the calculator (all views, no almanac tables).
                 NAVFULL is the same with the almanac-tables option; load one of the two.
  NAVINIT_FAST   builds the matrices, valid 2026-2030 (smaller and faster).
                 NAVINIT_FULL builds the FULL matrices instead (2000-2050, about twice the memory).

ONE-FILE INSTALL (NAV and INIT together, FAST matrices 2026-2030, no almanac tables)
  NAVALL_FAST   all nine views               19,067 lines to load, 12,538 stay after INIT
  NAVCOMP_FAST  compact: 1 ALMANAC 2 CHART   14,946 lines to load,  8,417 stay after INIT
                4 SKY 9 ALLSKY
  rejig build/NAVCOMP_FAST.txt -o NAVCOMP_FAST.p47, load it, XEQ "NAV".
  NAVTXT_FAST   text only, no drawing        10,582 lines to load,  4,051 stay after INIT
                NAV asks DATE UTC LAT LON and writes the almanac page into registers
                R50 ... R76 (one line each); X = "LINES R50-R76". Read them in the
                register browser (or RCL 50, RCL 51 ...). XEQ "NAV" again for another time.
  The first NAV builds the matrices (INIT, takes a while), deletes INIT (DELP "INIT") and
  sets flag 81; later runs go straight to the menu. To load the file again (new period):
  CF 81 first, so the new INIT is run and deleted too.

1. LOAD THE PROGRAMS (two files: NAVFULL_NOTBL + NAVINIT_FAST)
   Copy both .p47 files to the calculator (USB disk) and load them as you load any
   program file (I/O menu, READP).

2. BUILD THE MATRICES (once)
   XEQ "INIT"          takes a while (it stores a few thousand numbers); it ends with
                       MATRICES READY: FAST 2026-2030.
   The matrices (VL VB VR, NU, ST, ML MB MCL MCB, the planets ...) now stay in memory.

3. DELETE THE INIT PROGRAM (frees memory - the matrices stay)
   NAVINIT is one program, INIT (the matrix builders are numbered labels inside it).
   Delete it: GTO "INIT", then CLP.
   Do not use CLPALL: it would delete NAV and the views as well.
   (Run INIT again only for a new period: load NAVINIT again, XEQ "INIT", delete it again.)

4. RUN
   Only NAV has a name; the other programs show as N01, N02 ... (build/NAVFULL_LABELS.txt
   says which is which). Start everything from NAV:
   XEQ "NAV"  -> first NAV asks (once):
     DATE  YYYY.MMDD      e.g. 2026.0927
     UTC   HH.MMSS        e.g. 18.30
     LAT   DD.MMmm        e.g. 25.12   (25 deg 12 min N; minus = S)
     LON   DDD.MMmm       e.g. 55.18   (55 deg 18 min E; minus = W)
   (R/S keeps the value shown.) Then the menu on the graphics screen, with the date and time:
     1 ALMANAC  2 CHART  3 TEXT  4 SKY  5 SMALL  6 SPLIT  7 BODY  8 ANIM  9 ALLSKY  0 END
   The menu title: ALMANAC 47, VALID (the period of the matrices, stored by INIT as VAL),
   the date, time and DR position in use.
   Press the number key (no R/S): the item is highlighted and the view is drawn.
   On a drawn view:  +  back to the menu
                     UP arrow    the same view one hour later
                     DOWN arrow  the same view one hour earlier
   (the hours added stay for the other views; the menu title shows the time in use)
   4 SKY: any other key shows the next body. 3 TEXT: R/S for the next lines, EXIT ends
   (XEQ "NAV" again). 0 on the menu ends NAV. New date or position: XEQ "NAV" again.
     1 ALMANAC  GHA, Dec, Hc, Zn of Sun, Moon, planets, brightest stars; twilight, rise/set,
                meridian passage, Moon
     2 CHART    horizon chart left, the bodies' HC ZN right
     3 TEXT     the almanac as text, two lines per R/S
     4 SKY      horizon chart, R/S names each body in turn (EXIT to stop)
     5 SMALL    short almanac (Sun, Moon, 1 planet, 3 stars)
     6 SPLIT    horizon chart on top, short almanac below
     7 BODY     one body: key its number (stars 1-58, Sun 60, Moon 61, planets 62-65)
     8 ANIM     the Sun and the Moon moving over 12 hours (24 frames, 1 s each)
     9 ALLSKY   the whole sky: over the horizon above, under the horizon below

   An X in the top right corner: the date is outside the matrices' period (FAST: 2026-2030).

MEMORY (estimate): programs about 40 KB, FAST matrices about 50 KB (FULL about 90 KB).

DOES NOT REPLACE THE NAUTICAL ALMANAC.
