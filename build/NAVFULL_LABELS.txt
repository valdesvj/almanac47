NAVFULL / NAVFULL_NOTBL - program labels
==========================================
Label on the calculator, original name (sources, build/dev/, documentation), what it does.
Only NAV keeps its name. FONT = a text-drawing routine (draws on the graphics screen with
AGRAPH, one call per glyph column): Z = row of the base line (0 = bottom), Y = column,
X = text or number; returns Y = row, X = next column. PTXS is the C47 status-bar font
(bold capitals 12 px, glyphs from the firmware, GPL-3.0), PTXT a small 3x5 font.

NAV     NAV     graphic menu (KEY?): key 1-9, asks DATE UTC LAT LON, runs the view; 0 ends (the only named program)
N01     ALMF    view 1 ALMANAC: GHA, Dec, Hc, Zn table of Sun, Moon, planets, stars; twilight, rise/set, Moon
N02     HALMV   view 2 CHART: horizon chart left, Hc/Zn of 10 bodies right
N03     ALMR    view 3 TEXT: the almanac page as text in R50-R76 (and the stack and lettered registers); NAV ends in REGS
N04     HORZ    view 4 SKY: horizon chart, info line per body (any key: next body, + back to the menu)
N05     ALMS    view 5 SMALL: short almanac (Sun, Moon, 1 planet, 3 stars)
N06     HALMH   view 6 SPLIT: horizon chart on top, short almanac below
N07     BODY    view 7 BODY: list above the horizon, pick one body, its pages and chart
N08     SDM     text for ALMT: degrees and minutes "ddd°mm.m'" as a string
N09     SNS     text for ALMT: latitude with N / S
N10     SEW     text for ALMT: longitude with E / W
N11     SZN     text for ALMT: azimuth "ddd.d°"
N12     SHM     text for ALMT: time "hh:mm" (--:-- when no event)
N13     SF1     text for ALMT: number with one decimal
N14     SINT    text for ALMT: whole number
N15     SDAT    text for ALMT: date "dd-mm-yyyy" from a Julian Date
N16     SUNA    Sun: VSOP87 series (matrices VL VB VR), nutation, aberration -> GHA, Dec, GHA Aries
N17     SUNG    Sun GHA/Dec for the sunrise iterations (tables if loaded, else SUNF)
N18     SUNF    Sun, low-precision formula (0.01 deg) for sunrise/twilight
N19     SER     sum of one series matrix with the matrix functions (COS, DOT)
N20     SERT    the time vectors SV1 SV2 used by SER
N21     NUT     nutation in longitude and obliquity (matrix NU)
N22     STAR    star: SUNA, then STR2
N23     STR2    star GHA/Dec: catalogue ST, precession, aberration, nutation (after SUNA)
N24     SQK     star, quick sin(Hc) from the catalogue (to skip stars below the horizon)
N25     MOON    Moon: SUNA, then MOO2
N26     MOO2    Moon GHA, Dec, HP, SD: Meeus series (matrices ML MB MCL MCB) after SUNA
N27     MOOQ    Moon, quick low-precision formula (BODY list, ANIM)
N28     PLAN    planet: SUNA, then PLN2
N29     PLN2    planet GHA/Dec/SHA/HP: VSOP87 series with light-time, after SUNA
N30     PLN3    planet for the screens: quick position first, full series only if it can be above the horizon
N31     PLNQ    planet, quick position from mean elements (BODY list)
N32     CHZ     sight reduction with all inputs: Dec, GHA, lat, lon -> Hc, Zn
N33     HCZ     sight reduction: Y = Dec, X = GHA -> Hc (R96), Zn (R97), sin Hc ("SHC")
N34     HCZ0    sight reduction for Dec 0 (equator points)
N35     HCZQ    celestial equator: start of the dot-by-dot rotation
N36     HCZR    celestial equator: next point by rotation (no trig)
N37     HCZI    keeps sin/cos of the latitude for HCZ
N38     DHA     inverse: from Hc and Zn back to Dec and GHA (star identification)
N39     RISE    sunrise time UT (SUNRISE program)
N40     SET     sunset time UT
N41     NTWA    nautical twilight, morning, UT
N42     NTWP    nautical twilight, evening, UT
N43     CTWA    civil twilight, morning, UT
N44     CTWP    civil twilight, evening, UT
N45     TRAN    meridian passage of the Sun, UT
N46     PHAS    Moon phase: SUNA, then PHA2
N47     PHA2    Moon phase after SUNA: illumination % and age in days
N48     SBRT    star number by brightness rank (1st brightest ... 58th)
N49     SNMU    star name from its number
N50     TGET    almanac tables (TBL): Chebyshev lookup (not in NAVFULL_NOTBL)
N51     CWID    pixel width of a character in the PROMPT font (to align ALMT)
N52     PTXS    FONT big (C47 status-bar font, 12 px, AGRAPH): draw a string - Z row, Y column, X text
N53     PINS    FONT big: whole number
N54     PF1S    FONT big: number with one decimal
N55     PHMS    FONT big: hh:mm from hours
N56     PDMS    FONT big: degrees and minutes "ddd mm.m" with sign
N57     PDTS    FONT big: date "dd-mm-yyyy" from a Julian Date
N58     PZNS    FONT big: azimuth "ddd.d"
N59     PHLS    FONT big: horizontal line (X = length in pixels)
N60     PTXT    FONT small (3x5, AGRAPH): draw a string - Z row, Y column, X text
N61     PTNS    FONT small: whole number
N62     PT1     FONT small: number with one decimal
N63     HANIM   view 8 ANIM: the Sun and the Moon moving on the whole-sky chart (24 frames)
N64     ALLSKY  view 9 ALLSKY: whole sky, over the horizon above, under the horizon below
N65     WPLS    waits for the + key (KEY?): every view holds its screen until +, then back to the menu
N66     CSUN    Sun from the cache (matrix ALMC); computes the whole sky (CALC) only for a new time or place
N67     CMOO    Moon from the cache
N68     CPLN    planet from the cache
N69     CSTR    star R82 from the cache
N70     CSQK    
N71     CHCZ    
N72     CPHA    Moon phase from the cache
N73     CNTA    nautical twilight am from the cache (the five sun times: computed once per date and place)
N74     CRIS    sunrise from the cache
N75     CTRN    meridian passage from the cache
N76     CSET    sunset from the cache
N77     CNTP    nautical twilight pm from the cache
N78     CALC    computes Sun, Moon, planets, stars (GHA Dec Hc Zn) into matrix ALMC
N79     CEQQ    
N80     CEQR    

NAVFULL_NOTBL has no TGET; its labels are the same (N50 is simply missing there).
