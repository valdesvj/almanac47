NAVCOMP - program labels (NAV keeps its name; load NAVINIT_FAST or NAVINIT_FULL too:
the first NAV runs INIT, flag 81 remembers it; then delete INIT by hand; CF 81 before loading INIT again)

NAV     NAV     graphic menu (KEY?): asks DATE UTC LAT LON, key 1-7 a view, 8 INFO, 9 SNAP, 0 ends (the only named program; INFO page inside)
INIT    INIT    (NAVINIT file) builds the matrices; run by the first NAV, then delete it
N01     ALMF    view 1 ALMANAC: GHA, Dec, Hc, Zn table of Sun, Moon, planets, stars; twilight, rise/set, Moon
N02     HALMV   view 2 CHART: horizon chart left, Hc/Zn of 10 bodies right (no ARIES, no Moon line)
N03     HORZ    view 4 SKY: horizon chart, info line per body every 3 s (+ back to the menu, arrows one hour)
N04     SUNA    Sun: VSOP87 series (matrices VL VB VR), nutation, aberration -> GHA, Dec, GHA Aries
N05     SUNG    Sun GHA/Dec for the sunrise iterations (tables if loaded, else SUNF)
N06     SUNF    Sun, low-precision formula (0.01 deg) for sunrise/twilight
N07     SER     sum of one series matrix with the matrix functions (COS, DOT)
N08     SERT    the time vectors SV1 SV2 used by SER
N09     NUT     nutation in longitude and obliquity (matrix NU)
N10     STAR    star: SUNA, then STR2
N11     STR2    star GHA/Dec: catalogue ST, precession, aberration, nutation (after SUNA)
N12     SQK     star, quick sin(Hc) from the catalogue (to skip stars below the horizon)
N13     MOON    Moon: SUNA, then MOO2
N14     MOO2    Moon GHA, Dec, HP, SD: Meeus series (matrices ML MB MCL MCB) after SUNA
N15     MOOQ    Moon, quick low-precision formula (BODY list, ANIM)
N16     PLAN    planet: SUNA, then PLN2
N17     PLN2    planet GHA/Dec/SHA/HP: VSOP87 series with light-time, after SUNA
N18     PLN3    planet for the screens: quick position first, full series only if it can be above the horizon
N19     PLNQ    planet, quick position from mean elements (BODY list)
N20     CHZ     sight reduction with all inputs: Dec, GHA, lat, lon -> Hc, Zn
N21     HCZ     sight reduction: Y = Dec, X = GHA -> Hc (R96), Zn (R97), sin Hc ("SHC")
N22     HCZ0    sight reduction for Dec 0 (equator points)
N23     HCZQ    celestial equator: start of the dot-by-dot rotation
N24     HCZR    celestial equator: next point by rotation (no trig)
N25     HCZI    keeps sin/cos of the latitude for HCZ
N26     DHA     inverse: from Hc and Zn back to Dec and GHA (star identification)
N27     RISE    sunrise time UT (SUNRISE program)
N28     SET     sunset time UT
N29     NTWA    nautical twilight, morning, UT
N30     NTWP    nautical twilight, evening, UT
N31     CTWA    civil twilight, morning, UT
N32     CTWP    civil twilight, evening, UT
N33     TRAN    meridian passage of the Sun, UT
N34     PHAS    Moon phase: SUNA, then PHA2
N35     PHA2    Moon phase after SUNA: illumination % and age in days
N36     SBRT    star number by brightness rank (1st brightest ... 58th)
N37     SNMU    star name from its number
N38     PTXS    FONT big (C47 status-bar font, 12 px, AGRAPH): draw a string - Z row, Y column, X text
N39     PINS    FONT big: whole number
N40     PF1S    FONT big: number with one decimal
N41     PHMS    FONT big: hh:mm from hours
N42     PDMS    FONT big: degrees and minutes "ddd mm.m" with sign
N43     PDTS    FONT big: date "dd-mm-yyyy" from a Julian Date
N44     PZNS    FONT big: azimuth "ddd.d"
N45     PHLS    FONT big: horizontal line (X = length in pixels)
N46     PTXT    FONT small (3x5, AGRAPH): draw a string - Z row, Y column, X text
N47     PTNS    FONT small: whole number
N48     PT1     FONT small: number with one decimal
N49     ALLSKY  view 7 ALLSKY: whole sky, over the horizon above, under the horizon below
N50     WPLS    every view holds its screen here (KEY?): + back to the menu, up / down arrow one hour later / earlier
N51     CSUN    Sun from the cache (matrix ALMC); computes the whole sky (CALC) only for a new time or place
N52     CMOO    Moon from the cache
N53     CPLN    planet from the cache
N54     CSTR    star R82 from the cache
N55     CSQK    star from the cache: over the horizon test (computes the star the first time: SQK, STR2, HCZ)
N56     CHCZ    Hc Zn from the cache for the body just read (else the real HCZ)
N57     CPHA    Moon phase from the cache
N58     CNTA    nautical twilight am from the cache (the five sun times: computed once per date and place)
N59     CRIS    sunrise from the cache
N60     CTRN    meridian passage from the cache
N61     CSET    sunset from the cache
N62     CNTP    nautical twilight pm from the cache
N63     CALC    computes Sun, Moon, planets (GHA Dec Hc Zn) into matrix ALMC; stars marked to compute when asked
N64     CEQQ    celestial equator of the charts: start (replay from matrix ALMQ, or compute and record)
N65     CEQR    celestial equator of the charts: next dot (from ALMQ, or HCZR and record)
