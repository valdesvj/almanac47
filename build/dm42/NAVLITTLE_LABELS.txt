NAVLITTLE - program labels (NAV keeps its name; INIT is NAVINIT_LITTLE)

NAV     NAV     graphic menu (KEY?): asks DATE UTC LAT LON, key 1-8 a view, 9 INFO, 0 ends (the only named program; INFO page inside)
N01     ALMF    view 1 ALMANAC: GHA, Dec, Hc, Zn table of Sun, Moon, planets, stars; twilight, rise/set, Moon
N02     SUNA    Sun: VSOP87 series (matrices VL VB VR), nutation, aberration -> GHA, Dec, GHA Aries
N03     SUNG    Sun GHA/Dec for the sunrise iterations (tables if loaded, else SUNF)
N04     SUNF    Sun, low-precision formula (0.01 deg) for sunrise/twilight
N05     SER     sum of one series matrix with the matrix functions (COS, DOT)
N06     SERT    the time vectors SV1 SV2 used by SER
N07     NUT     nutation in longitude and obliquity (matrix NU)
N08     STAR    star: SUNA, then STR2
N09     STR2    star GHA/Dec: catalogue ST, precession, aberration, nutation (after SUNA)
N10     SQK     star, quick sin(Hc) from the catalogue (to skip stars below the horizon)
N11     CHZ     sight reduction with all inputs: Dec, GHA, lat, lon -> Hc, Zn
N12     HCZ     sight reduction: Y = Dec, X = GHA -> Hc (R96), Zn (R97), sin Hc ("SHC")
N13     HCZ0    sight reduction for Dec 0 (equator points)
N14     HCZI    keeps sin/cos of the latitude for HCZ
N15     DHA     inverse: from Hc and Zn back to Dec and GHA (star identification)
N16     RISE    sunrise time UT (SUNRISE program)
N17     SET     sunset time UT
N18     NTWA    nautical twilight, morning, UT
N19     NTWP    nautical twilight, evening, UT
N20     CTWA    civil twilight, morning, UT
N21     CTWP    civil twilight, evening, UT
N22     TRAN    meridian passage of the Sun, UT
N23     SBRT    star number by brightness rank (1st brightest ... 58th)
N24     SNMU    star name from its number
N25     PTXS    FONT big (C47 status-bar font, 12 px, AGRAPH): draw a string - Z row, Y column, X text
N26     PINS    FONT big: whole number
N27     PF1S    FONT big: number with one decimal
N28     PHMS    FONT big: hh:mm from hours
N29     PDMS    FONT big: degrees and minutes "ddd mm.m" with sign
N30     PDTS    FONT big: date "dd-mm-yyyy" from a Julian Date
N31     PZNS    FONT big: azimuth "ddd.d"
N32     PHLS    FONT big: horizontal line (X = length in pixels)
N33     PTXT    FONT small (3x5, AGRAPH): draw a string - Z row, Y column, X text
N34     PTNS    FONT small: whole number
N35     PT1     FONT small: number with one decimal
N36     WPLS    every view holds its screen here (KEY?): + back to the menu, up / down arrow one hour later / earlier
