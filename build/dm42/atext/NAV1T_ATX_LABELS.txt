NAV1T_ATX - program labels (NAV keeps its name; INIT is NAVINIT_LITTLE)

NAV     NAV     graphic menu (KEY?): asks DATE UTC LAT LON, key 1-7 a view, 8 INFO, 9 SNAP, 0 ends (the only named program; INFO page inside)
N01     ALMF    view 1 ALMANAC: GHA, Dec, Hc, Zn table of Sun, Moon, planets, stars; twilight, rise/set, Moon
N02     ALMR    view 3 TEXT: the almanac page as text in R50-R76 (and the stack and lettered registers); NAV ends in REGS
N03     SDM     text: degrees and minutes "ddd°mm.m'" as a string
N04     SNS     text: latitude with N / S
N05     SEW     text: longitude with E / W
N06     SZN     text: azimuth "ddd.d°"
N07     SHM     text: time "hh:mm" (--:-- when no event)
N08     SF1     text: number with one decimal
N09     SINT    text: whole number
N10     SDAT    text: date "dd-mm-yyyy" from a Julian Date
N11     SUNA    Sun: VSOP87 series (matrices VL VB VR), nutation, aberration -> GHA, Dec, GHA Aries
N12     SUNG    Sun GHA/Dec for the sunrise iterations (tables if loaded, else SUNF)
N13     SUNF    Sun, low-precision formula (0.01 deg) for sunrise/twilight
N14     SER     sum of one series matrix with the matrix functions (COS, DOT)
N15     SERT    the time vectors SV1 SV2 used by SER
N16     NUT     nutation in longitude and obliquity (matrix NU)
N17     STAR    star: SUNA, then STR2
N18     STR2    star GHA/Dec: catalogue ST, precession, aberration, nutation (after SUNA)
N19     SQK     star, quick sin(Hc) from the catalogue (to skip stars below the horizon)
N20     CHZ     sight reduction with all inputs: Dec, GHA, lat, lon -> Hc, Zn
N21     HCZ     sight reduction: Y = Dec, X = GHA -> Hc (R96), Zn (R97), sin Hc ("SHC")
N22     HCZ0    sight reduction for Dec 0 (equator points)
N23     HCZI    keeps sin/cos of the latitude for HCZ
N24     DHA     inverse: from Hc and Zn back to Dec and GHA (star identification)
N25     RISE    sunrise time UT (SUNRISE program)
N26     SET     sunset time UT
N27     NTWA    nautical twilight, morning, UT
N28     NTWP    nautical twilight, evening, UT
N29     CTWA    civil twilight, morning, UT
N30     CTWP    civil twilight, evening, UT
N31     TRAN    meridian passage of the Sun, UT
N32     SBRT    star number by brightness rank (1st brightest ... 58th)
N33     SNMU    star name from its number
N34     TGET    almanac tables (TBL): Chebyshev lookup (not in NAVFULL_NOTBL)
N35     PTXS    TEXT with ATEXT (standard font; Didier's N03 trick) and the number printers - Z row, Y column, X text or number
N36     PINS    FONT big: whole number
N37     PF1S    FONT big: number with one decimal
N38     PHMS    FONT big: hh:mm from hours
N39     PDMS    FONT big: degrees and minutes "ddd mm.m" with sign
N40     PDTS    FONT big: date "dd-mm-yyyy" from a Julian Date
N41     PZNS    FONT big: azimuth "ddd.d"
N42     PHLS    FONT big: horizontal line (X = length in pixels)
N46     PSYM    the AGRAPH symbols of the bodies - Z row, Y column, X symbol
N47     WPLS    every view holds its screen here (KEY?): + back to the menu, up / down arrow one hour later / earlier
