LBL "ANT"
REM "ANT - example of AGRAPH and GRMOD on the C47."
REM "Writes a small A at a random place, then inverts it with GRMOD 3 (XOR): you see the"
REM "A turn into a bug (an ant). Drawn over whatever is on the screen (no CLLCD)."
REM "AGRAPH reg: draws ONE column; the bits of the number in reg are the pixels,"
REM "bit 0 = bottom pixel. Stack: Y = row, X = column; afterwards X = next column."
REM "GRMOD reg: how AGRAPH draws (mode number in reg): 0 = OR (switch pixels on),"
REM "1 = SET, 2 = OFF, 3 = XOR (switch every pixel it touches: on -> off, off -> on)."
REM "The A is the 5x7 letter made 2 times bigger: 10 pixels wide, 14 high."
REM "Registers: R30 = column (x), R31 = row (y), R32 = column pattern, R00/R03 = mode."
REM "Screen: 400 x 240 pixels, (0,0) = bottom left."
REM "--- 1. Random place, saved in R30/R31 (both passes must use the same place) ---"
REM "Column 0-389 (the A is 10 wide)"
RAN#
390
×
IP
STO 30
REM "Row 72-205: above the menu area (bottom ~70 rows), below the status bar (top 20 rows)"
RAN#
134
×
IP
72
+
STO 31
REM "--- 2. Prepare ---"
REM "WSIZE 16: binary numbers up to 15 bits (the A is 14 pixels high, plus the sign bit)"
WSIZE 16
REM "GRMOD 0 = OR: AGRAPH only switches pixels on (normal drawing)"
0
STO 00
GRMOD 00
REM "--- 3. First pass: write the A, column by column ---"
RCL 31
RCL 30
REM "Left leg: 2 columns, 12 pixels on, the top 2 off"
111111111111#2
STO 32
R↓
AGRAPH 32
AGRAPH 32
REM "Middle: 6 columns, top bar (top 2 pixels) and crossbar (2 pixels in the middle)"
11000011000000#2
STO 32
R↓
AGRAPH 32
AGRAPH 32
AGRAPH 32
AGRAPH 32
AGRAPH 32
AGRAPH 32
REM "Right leg: the same as the left leg"
111111111111#2
STO 32
R↓
AGRAPH 32
AGRAPH 32
REM "Show the A for 1 second, so you see the inversion happen"
PAUSE 10
REM "--- 4. Second pass: invert the A ---"
REM "GRMOD 3 = XOR: every pixel AGRAPH touches is switched (on -> off, off -> on)"
3
STO 03
GRMOD 03
REM "A solid block (all bits on) exactly over the A, from the same saved place:"
REM "the A's pixels go off and its empty space goes on -> head, body and feelers: the bug"
RCL 31
RCL 30
11111111111111#2
STO 32
R↓
AGRAPH 32
AGRAPH 32
AGRAPH 32
AGRAPH 32
AGRAPH 32
AGRAPH 32
AGRAPH 32
AGRAPH 32
AGRAPH 32
AGRAPH 32
REM "--- 5. Tidy up and show ---"
REM "Always set GRMOD 0 again, or later drawing (other programs) would be XOR too"
0
STO 00
GRMOD 00
WSIZE 64
REM "Keep the bug on the screen for 5 seconds"
PAUSE 50
RTN
